# Datasets

## Overview

This folder contains the datasets used for the Marketing Power BI Dashboard.

The datasets contain information related to courses, marketing platforms, sources, students, and trainers. These datasets are used for data preparation, analysis, DAX calculations, and Power BI visualizations.

---

## 1. Course Data

**File:** `Course_data_3months(4).xlsx`

**Sheet:** `course_data`

This dataset contains course-level marketing and revenue information.

### Key information includes:

- Course
- Amount
- Payment
- Leads
- Converted
- Revenue
- Marketing source information

### Purpose

This dataset is used to analyze course-wise leads, conversions, revenue, and other course-related performance metrics.

---

## 2. Platforms Data

**File:** `Platforms_data_3months(3).xlsx`

**Sheet:** `Plarforms_data`

This dataset contains marketing platform performance information.

### Marketing platforms include:

- Instagram
- Facebook
- YouTube
- LinkedIn
- Just Dial

### Key information includes:

- Platform/source
- Leads
- Interested
- Converted
- Course
- Date-related information

### Purpose

This dataset is used to analyze marketing platform performance, leads, interested leads, conversions, and source conversion rates.

---

## 3. Source Data

**File:** `Source_data_3months(3).xlsx`

**Sheet:** `source_data`

This dataset contains source-wise information related to courses and leads.

### Key information includes:

- Course
- Source
- Leads
- Month
- Week

### Purpose

This dataset is used to analyze the distribution of leads across different marketing sources and courses.

---

## 4. Student Details

**File:** `Student_details_3months(3).xlsx`

**Sheet:** `Student_details`

This dataset contains student-related information used for analysis.

### Key information includes:

- Student details
- Course
- Trainer
- Source
- Contact information
- Date-related information

### Purpose

This dataset can be used to analyze student-level information and relationships between students, courses, trainers, and marketing sources.

### Privacy Note

This dataset may contain personally identifiable information such as student names, phone numbers, and email addresses.

The original file should not be shared publicly without appropriate authorization. An anonymized version should be used when publishing the project publicly.

---

## 5. Trainers Details

**File:** `Trainers_details_3months(3).xlsx`

**Sheet:** `Trainers_details`

This dataset contains trainer and batch-related information.

### Key information includes:

- Trainer details
- Batch information
- Course
- Student information
- Date-related information

### Purpose

This dataset can be used to analyze trainer, batch, course, and student-related information.

---

## Dataset Integration

The datasets are used together within the Power BI project to support data analysis and dashboard creation.

The data is prepared using Power Query and analyzed using DAX measures and Power BI visualizations.

---

## Data Preparation

The datasets may undergo the following preparation steps before analysis:

- Data type correction
- Data cleaning
- Removing unnecessary values
- Handling missing values
- Column transformation
- Creating calculated columns where required
- Establishing relationships between relevant tables
- Preparing data for DAX calculations

---

## Power BI Usage

The datasets support the following dashboard analysis:

- Total Leads
- Total Converted
- Total Revenue
- Conversion Rate
- Source Conversion Rate
- Profit Percentage
- Course-wise Revenue
- Course-wise Conversions
- Monthly Performance
- Weekly Performance
- Daily Conversion Trends
- Marketing Source Performance

---

## Data Privacy

The datasets should only be shared with authorized users.

Any dataset containing personal, confidential, customer, student, employee, or company information should be kept private or anonymized before public distribution.
