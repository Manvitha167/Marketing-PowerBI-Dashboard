# Marketing Dashboard - Power BI

## Project Overview

This project is an interactive Marketing Analytics Dashboard developed using Microsoft Power BI.

The dashboard provides a consolidated view of marketing performance, leads, conversions, revenue, course performance, and time-based trends.

The objective of this project is to transform raw data into meaningful insights using Power BI visualizations, Power Query, and DAX.

---

## Project Objectives

- Analyze total leads
- Analyze converted leads
- Monitor total revenue
- Calculate conversion rate
- Analyze marketing source performance
- Compare course-wise revenue
- Analyze course-wise conversions
- Analyze daily conversion trends
- Analyze weekly performance
- Analyze monthly revenue trends
- Monitor profit percentage
- Provide interactive filtering and analysis

---

## Dashboard Features

The Power BI dashboard contains interactive KPIs, charts, and filters for analyzing marketing performance.

### Key Performance Indicators

- Total Leads
- Total Converted
- Total Revenue
- Source Conversion Rate
- Profit Percentage

### Interactive Filters

The dashboard includes filters for:

- Source
- Course
- Month
- Week

### Visualizations

The dashboard includes visualizations such as:

- Revenue by Month
- Total Revenue by Course
- Source Data
- Daily Converted
- Converted by Course
- Weekly Data
