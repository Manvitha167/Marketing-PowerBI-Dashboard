# Marketing Dashboard - Project Documentation

## 1. Project Overview

The Marketing Dashboard is an interactive dashboard developed using Microsoft Power BI.

The dashboard is designed to analyze marketing performance using KPIs, interactive filters, and visualizations.

---

## 2. Dashboard KPIs

The dashboard contains the following key performance indicators:

- Total Leads
- Total Converted
- Total Revenue
- Source Conversion Rate
- Profit Percentage

---

## 3. Dashboard Filters

The dashboard provides interactive filters for:

- Source
- Course
- Month
- Week

These filters allow users to analyze the dashboard based on different categories and time periods.

---

## 4. Dashboard Visualizations

The dashboard contains visualizations for:

### Revenue by Month

Shows revenue performance across different months.

### Total Revenue by Course

Shows revenue generated by different courses.

### Source Data

Shows marketing performance based on different sources.

### Daily Converted

Shows converted leads on a daily basis.

### Converted by Course

Shows the number of conversions associated with each course.

### Weekly Data

Shows marketing performance across different weeks.

---

## 5. Marketing Sources

The dashboard includes marketing sources such as:

- Instagram
- Facebook
- YouTube
- LinkedIn
- Just Dial

## 6. Technologies Used

- Microsoft Power BI
- Power Query

---

## 7. Data Preparation

The source data is prepared and transformed using Power Query before being used for dashboard analysis.

Data preparation may include:

- Cleaning data
- Changing data types
- Removing unnecessary values
- Creating required columns
- Preparing data for analysis

---

## 8. Data Modeling

The Power BI data model is used to connect and organize the data required for the dashboard.

The model supports calculations and visualizations used throughout the report.

---

## 9. DAX

DAX (Data Analysis Expressions) is used to create measures and calculations for the dashboard.

The actual DAX formulas used in the Power BI file will be documented separately in:

`DAX_Measures.md`

---

## 10. Dashboard Interactivity

Users can interact with the dashboard using slicers and visual selections.

The available filters include:

- Source
- Course
- Month
- Week

Selecting values in these filters updates the related dashboard visuals.
